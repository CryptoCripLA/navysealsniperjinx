## 当前项目矩阵

### Pump.fun Market Lab

`pumpfun-market-lab` 是一个公开的原始数据实验室，基于北京时间完整一天的 Pump.fun 市场数据构建。

它包含：

- `pump_fun` bonding-curve / 内盘原始事件
- `pump_amm` PumpSwap / AMM / 外盘原始事件
- 单日 2000 万+ raw rows
- 可复现的小时级 manifest
- schema 与覆盖率报告
- 方便快速试跑的 parquet 样本文件

这个项目不是喊单，也不是把一天样本包装成策略。它的目标是把市场结构、数据覆盖和执行成本摆到台面上，让后续研究更诚实。

### Solana Meme 成本计算器

`solana-meme-cost-calculator` 是一个轻量的网页工具，用来估算一次 meme 交易的最低回本涨幅。

它关注：

- 买入/卖出平台费
- 滑点和价格冲击
- 优先费与网络费
- 小本金交易被固定成本吞掉的问题

### AI 研究工作流手册

`ai-research-playbook-cn` 是一个中文 AI 研究模板库，用来约束研究任务、回测检查和公开项目发布流程。

它的目标是让 AI 辅助研究更可复查，而不是只保留一句看起来很强的结论。
