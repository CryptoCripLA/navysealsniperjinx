## Regenerating archived reports

`REPLAY_REPORT.md` and `RESEARCH_REPORT.md` are outputs of scripts (`replay_analyzer.py`, `research_report.py`).
If you re-run those scripts, they will write a **fresh copy to the repo root** — not into this archive.
The archived versions are frozen snapshots; replace them manually if you want to update the archive.
